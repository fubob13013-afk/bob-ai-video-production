# 新手上手：从一句话开始

整理与署名：Bob

## 用户可直接复制的开场

“使用 $bob-ai-video-production，带我做一个AI视频。我想做【主题】，给【受众】看，用在【平台/场景】，大约【时长】。资料在【工作文件夹】，总预算【金额】元。我是新手，请先检查资料，帮我定脚本和风格，再做少量小样；需要旁白的话先让我听音色。”

不知道的项目写“不确定”即可。没有脚本也能开始；先做脚本和分镜，不直接批量花钱。

## Agent分步带领

1. **讲清楚要做什么**：用两三句话描述成片效果，建议横竖屏和节奏。用户有参考片先分析它，不从零重复提问。
2. **整理资料**：告诉用户现有内容够做哪些镜头，缺的是什么；需要补拍时给可执行拍摄说明，例如正面、侧面、光线与清晰度。
3. **优化脚本**：交付可读的分镜表，用“镜头、画面、声音、时长”表达，不先甩一堆参数。
4. **选生成方式**：有API则自动接入；只有网页会员则交逐镜复制任务卡。说明视频API、语音API分别做什么，不把音乐API用于旁白。
5. **接入账号**：指导用户在平台控制台开通目标模型并配置额度、密钥。实际页面可能变化，先核实官方文档。用户自行进行需要本人操作的注册、充值、认证等步骤；不索取密码或让用户把Key发进公开群。
6. **低成本小样**：说明预计费用、可控制的生成项和可能失败处，在授权范围内测试。让用户看到真正的短片；需要配音时再试听2–3种音色。
7. **完成全片**：按镜头生成、测量声音、调整节奏、合成字幕和成片。进度只报告实际结果，失败解释具体原因与下一步。
8. **交付和修改**：给可播放预览、成片文件、字幕及素材包。提示最值得用户检查的几处，例如名字读音、产品细节或专业说法，不要求用户逐项理解技术参数。

## 常见问题的解释方式

- “API是什么？”：把视频平台接到Agent的接口，减少逐镜复制；视频仍由选定平台生成。
- “会员能直接用吗？”：先核实平台账号与API计费，不能把网页会员额度当作API余额。
- “要多少钱？”：按当前模型、时长、分辨率和音频估算，留返工额度；成本估算不是最终账单。
- “能保证一遍过吗？”：先做代表性小样，减少后续返工；手部、多人对白、产品细节等仍需审核。
- “只想要成片，不想管参数”：Agent负责参数和文件组织，用户重点确认风格、内容、预算和音色。
- “我的环境没法调用API”：完成分镜、参考图和提示词，转网页手动生成后继续剪辑，不假装已完成生成。

新手友好是减少不必要的操作，不是省略真实预览、费用授权或内容审核。
