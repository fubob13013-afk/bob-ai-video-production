# 项目准备与分镜

整理与署名：Bob

## 准备哪些资料

最低条件是主题、用途和大致时长；脚本、照片、参考视频可以逐步补齐。Agent先整理文件索引，再判断哪些能直接用、哪些仅作参考、哪些需要生成。保留原始资料，用固定编号对应转换副本；转换失败记录原因，不替换或删除原件。根据当前工具处理DOCX、照片和视频，不要求用户安装所有可选依赖。

参考片分析节奏、风格、人物、机位与声音；产品/设备细节看清晰原图，不能靠缩略图猜功能。角色图、场景图、构图图分别标明用途，避免把多格人物图生成成多个人。

## 推荐目录

```text
项目/

```

目录仅为起点，不搬迁已经稳定的项目。新手只需提供工作文件夹，Agent负责整理。

## 分镜记录示例

```json
{
  "id": "01-03",
  "title": "展示使用场景",
  "seconds": 6,
  "mode": "generate",
  "scene": "明亮书房，主角坐在书桌旁",
  "action": "合上笔记本，抬头微笑",
  "camera": "固定中景",
  "voice": "把复杂的流程，变成清楚的一步。",
  "dialogue": "",
  "overlay": "简单一步",
  "references": ["角色参考.jpg", "书房参考.jpg"],
  "checks": ["角色服装一致", "产品外观准确", "无额外人物"]
}
```

使用生成、实拍、复用、静帧、图解等不同方式，以实际表现效果和费用决定。旁白与对白都可记录，但注明各自时间窗。镜头时长是初始计划，配音实测后再修订。

## 完整提示词模板

```text
[画幅]，[画风和材质]，[配色]，[光线]，适合[受众和用途]。
图片1只用于[角色身份/产品外观]；图片2用于[场景布局]。
保持[人物、服装、产品和场景中应一致的细节]。
场景：[地点与构图]。
动作：[一个明确、可见的动作及先后顺序]。
镜头：[固定/推进/跟随，选择清楚且不矛盾的方式]。
声音：[精确对白与说话者，或仅场景声；是否允许音乐]。
画面内[是否允许文字/标志]；避免[本镜容易出现的具体错误]。
```

方括号需由Agent填完，不能把模板原样交给新手。每镜包含完整风格约束，方便网页复制，也方便单镜API重做。统一风格不能替代具体动作，动静和镜头运动要说清楚。

## 网页端任务包

每镜一张任务卡：镜号、目标时长、对应参考图、完整提示词、声音要求、建议文件名、状态。页面支持复制整段提示词和打开参考图即可，不夸大成自动操作网页。生成结果按镜号保存后，Agent继续对齐与剪辑。

复用原始画面，重新核对台词、字幕和时长；不要把上一篇已带字幕的成片当干净素材。
