# Bob AI视频制作 Skill v2.0

整理与署名：Bob

适合讲解片、产品展示、宣传片、故事短片等。你提供主题或资料，Agent带你完成脚本、分镜、视频生成、音色试听、旁白与字幕对齐、剪辑和成片交付。不要求先懂API或准备完整脚本。

## 安装或直接使用

解压后，将整个bob-ai-video-production文件夹放进工具的Skill目录。Codex常用目录：Windows为%USERPROFILE%\.codex\skills\；macOS/Linux为~/.codex/skills/。配置了CODEX_HOME时使用其skills目录。其他Agent工具按它自己的安装方式操作，不假定所有工具都支持Skill或直接上传ZIP。

更新旧版时替换同名Skill目录，保留自己的项目文件，重新打开会话。也可以把SKILL.md及references一起交给支持文件读取的Agent，说明“按这套流程带我做”；仅贴SKILL.md时还需提供它引用的资料。

## 复制这句话开始

“使用 $bob-ai-video-production，带我做一个AI视频。我想做【主题】，给【受众】看，用在【平台】，大约【时长】。资料在【文件夹】，总预算【金额】元。我是新手，请先帮我整理需求、脚本和分镜，再做小样；有旁白的话先让我确认音色。”

不确定的地方直接说“不确定”。没有API也能先做脚本和提示词，使用网页逐镜生成；是否能自动剪辑取决于Agent的工具条件。

## API与费用

视频使用你选定的视频服务，Seedance/火山方舟是支持的示例；旁白使用MiniMax语音/TTS API，Music API是音乐服务。网页会员和API额度需分别核实。各人自行配置账号、模型权限和密钥，不要在朋友圈、群聊或公开文档中分享Key。包内不含有效密钥或原项目素材。

Agent先检查配置、展示请求和估算，再在授权预算内制作。费用以服务商实际账单为准，小样和返工也可能收费。请求示例是占位模板，不能原样提交；模型、音色和参数要按当前官方文档核实。

## 包内内容

SKILL.md是执行入口；references是新手上手、分镜、API预算与配音交付说明；assets是请求模板；scripts是有限的API执行和单段声音对齐辅助工具。辅助脚本需Python3，对齐另需FFmpeg/FFprobe，Agent负责检查环境，不要求新手先逐个安装。

这是一套制作流程与辅助工具，不保证一遍过，也不包含完整的一键剪辑程序。通用流程署名Bob，第三方服务与工具保留原归属。
